# payment_call_predictor
Payment Call Predictor
Final Project service payment call predictor

This project uses the following packages:
pandas
sklearn.model_selection train_test_split
sklearn.linear_model  LogisticRegression
klearn.metrics  classification_report
sklearn.metrics
pickle
numpy
flask Flask, request, render_template

The project aims to create a model to predict the likelihood of a policyholder making a service payment call. This scenario concerns a fictional insurance company wanting to send emails to encourage customers to pay through automatic channels rather than calling.

Extra credit was possible by creating an app from the model using Flask. This addition was attempted, but time constraints prevented the completion of the app. At this point, everything except the app.py file should be working.
