# payment_call_predictor
Payment Call Predictor

This project was completed as the final assignment for the Analysis, Visualization, and Prediction in Analytics course at UAlbany. Simulating a real-world scenario, the project calls for assuming a position at an insurance company tasked with creating a predictive model to evaluate customer payment information and identify specific trends. 

This project uses the following packages:
pandas
sklearn.model_selection train_test_split
sklearn.linear_model  LogisticRegression
klearn.metrics  classification_report
sklearn.metrics
pickle
numpy
flask Flask, request, render_template
